## 四.项目模块介绍
- abi：存放合约编译完成之后的 JSON 文件
- caller: 调用合约的板块
- config：配置模块
- parser: 合约事件解析器
- schedule: 定时任务执行的调度器
- services：项目 API 的出口
- synchronizer: 同步合约事件的板块
- worker: 业务处理板块
- typeorm：数据库结构定义
